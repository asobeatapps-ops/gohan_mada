## 共有ランキング（Firebase設定待ち）

ゲーム専用の新しいFirebaseプロジェクトを使います。作成・接続・公開前確認の手順は [RANKING_SETUP.md](RANKING_SETUP.md) を参照してください。まだ本番Firebaseとの接続確認は完了していません。
